# Tidecove — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Data monetisation lead (seller)

- As a data monetisation lead, I want to publish a priced dataset that stays in my VPC, so that I can sell access without surrendering custody.
- As a data monetisation lead, I want one licence and price to appear across partner marketplaces, so that I am not renegotiating terms per channel.
- As a data monetisation lead, I want to revoke or amend a licence and see which active entitlements are affected, so that regulatory change does not leave stale grants live.
- As a data monetisation lead, I want usage attestations per buyer, so that I can prove who consumed the asset under which purpose.

### AI product / data science buyer

- As an AI product manager, I want to search by sector, licence, and compute-in-place vs download, so that I do not waste budget on unusable gravity-bound assets.
- As a data scientist, I want a purchase to unlock a time-boxed access credential automatically, so that procurement does not become a weeks-long legal side quest for every training set.
- As a data scientist, I want commons datasets clearly separated from paid ones, so that I can prototype before committing spend.

### Marketplace operator

- As a marketplace operator, I want to curate a vertical catalogue over shared protocol offers, so that I compete on discovery UX rather than exclusive lock-in of supply.
- As a marketplace operator, I want fiat checkout with disclosed take-rate, so that enterprise buyers can purchase without holding network tokens.

### Compliance officer

- As a compliance officer, I want every personal-data offer to declare lawful basis and purpose, so that we can refuse non-compliant purchases.
- As a compliance officer, I want an exportable provenance pack for an asset (owner, licence history, access events), so that we can answer regulator or partner diligence.

### Network / platform administrator

- As a platform administrator, I want keeper performance and penalties visible, so that availability failures have commercial consequence.
- As a platform administrator, I want to suspend a participant who repeatedly violates licence or spam thresholds, so that the commons does not degrade into low-quality noise.
